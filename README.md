# Dinosaur-Game
A simple dinozer game built using HTML ,CSS  and JavaScript.

🦖 Dinosaur Game

📌 Project Overview

Dinosaur Game is a simple and interactive browser-based game built using HTML, CSS, and JavaScript. The player controls a dinosaur character that jumps over obstacles and eats food to score points. This project focuses on basic game development concepts such as animations, event handling, and collision detection while providing an enjoyable learning experience.

🎯 Objective

The main objective of this project is to improve frontend development skills and understand core JavaScript game logic by building a real-time playable game.

⭐ Features

Smooth dinosaur jumping animation

Food collection and scoring system

Obstacle avoidance gameplay

Real-time interactions

Simple and beginner-friendly design


🛠 Technologies Used

HTML, CSS, JavaScript

▶ How to Play

Open the index.html file in a web browser and press the jump key to avoid obstacles while collecting food to increase your score.
